# Virginia First-Time Homebuyer Guide

Standalone, self-contained HTML guide for Virginia (Greater Richmond) first-time buyers, adapted from the Colorado buyer guide on Netlify (anastasia-buyer-guide.netlify.app).

- `index.html` plus `img/` is the whole page. Open it locally or deploy the folder as-is (for example, drag it into Netlify).
- Standalone repo, separate from the anastasiamorganrealtor.com website. No build step: the repo root is the site root, so it can be connected to Netlify directly (publish directory `.`).

Content notes:
- Program facts (Virginia Housing grant and Plus Second, DHCD local DPA, HOME of Virginia counseling, first-time buyer savings account, recordation and grantor tax) are sourced in the Sources line of the Virginia Programs section. Amounts and limits change; recheck before reuse.
- Inspection costs are ballpark estimates, not verified Central Virginia pricing.
- House photos are Unsplash images from a "Virginia house" search; only the skyline and river shots are location-tagged Richmond, VA.
